### 🛠️ What I Do

- **Systems, Linux & Low-Level:** Daily-driving **Arch Linux** & managing headless **Ubuntu/Debian** servers (`systemd`, hardening, profiling). Compiling custom Android & Linux kernels with **Clang/LLVM**, upstream patching, **KernelSU/Magisk** integration, and custom ROM/fastboot operations.
- **DevOps, Infra & Networking:** Managing KVM VPS environments, **Docker & Docker Compose**, **PM2** daemons, **Nginx** reverse proxies (SSL/TLS, WebSockets, load balancing), **Cloudflare** (Zero Trust Tunnels/`cloudflared`, Workers, WAF/DNS), and **WireGuard / Tailscale** mesh networks.
- **Backend, Bots & AI Routing:** Developing event-driven WhatsApp bots with **Node.js, TypeScript, and Baileys**, media transcoding pipelines with **FFmpeg**, REST APIs, and custom LLM API gateways (**OpenAI, Gemini, Anthropic**) backed by **PostgreSQL, MongoDB, MySQL, and Redis**.
- **Fullstack Web Development:** Building responsive web apps, dashboards, and landing pages with **React, Next.js, Tailwind CSS**, and automated **GitHub Actions** CI/CD workflows.
